Players
Solo Keyboard drives only the active player with Player 1's controls; digits 1-4 switch which player is active (testing helper).
Speed
Turbo fast-forwards past the 60 fps pace; Pause freezes all players at once. Both are remappable (Controls → Remap Hotkeys).
View
Arrange the linked screens like a video call. Cycle View (F8) and Cycle Focus (F9) flip through them; both are remappable. Background shows behind the tiles; Player Outlines toggles the colored borders; Debug Log toggles the stats ticker.
Audio
Each GBA instance outputs one mixed stream (music + SFX together). Pick whose mix you hear, or blend all players.
Controls
Remap per-player GBA buttons and the global hotkeys (turbo / quick save / load / pause). Gamepads are assigned by controller slot (controller #1 → P1). Remaps persist in this browser.
